# Tool Sites - Online Utilities Collection

A collection of free, lightweight online tools built with pure HTML, Tailwind CSS, and vanilla JavaScript. No backend required - all tools run entirely in your browser.

## 🚀 Live Demo

**[https://www.qmsu.top](https://www.qmsu.top)**

## 📦 Available Tools

### 1. QR Code Generator
Generate QR codes with custom colors, logo overlay, and batch mode.
- **Features**: Custom colors, logo upload, PNG/SVG download, batch ZIP export
- **URL**: `/qr-generator/`

### 2. Image Compressor
Compress and resize images directly in your browser.
- **Features**: Drag & drop upload, quality control, format conversion, batch processing
- **URL**: `/image-compressor/`

### 3. JSON Formatter
Format, validate, and query JSON data with syntax highlighting.
- **Features**: Syntax highlighting, JSONPath queries, tree/code view, error detection
- **URL**: `/json-formatter/`

### 4. CSS Gradient Generator
Create beautiful CSS gradients visually.
- **Features**: Linear/radial gradients, color stops, angle control, 20+ presets
- **URL**: `/css-gradient/`

### 5. Meta Tag Generator
Generate and preview meta tags for SEO and social media.
- **Features**: Google/Facebook/Twitter previews, Open Graph, Twitter Cards
- **URL**: `/meta-tag-generator/`

### 6. Regex Tester
Test and visualize regular expressions in real-time.
- **Features**: Match highlighting, capture groups, cheat sheet, replace function
- **URL**: `/regex-tester/`

### 7. Password Generator
Generate secure passwords, PINs, and passphrases.
- **Features**: Strength indicator, multiple modes, history, crypto-secure random
- **URL**: `/password-generator/`

## 🛠️ Tech Stack

- **Frontend**: Pure HTML5, Tailwind CSS (CDN), Vanilla JavaScript
- **No Build Step**: Single-file applications
- **No Backend**: All processing happens client-side
- **SEO Optimized**: Meta tags, Open Graph, JSON-LD structured data
- **Analytics Ready**: Google Analytics 4, Microsoft Clarity placeholders

## 🚀 Deployment

This project is configured for GitHub Pages deployment:

1. Fork or clone this repository
2. Go to repository Settings > Pages
3. Select "Deploy from a branch" and choose `main` branch
4. Your site will be live at `https://www.qmsu.top/`

## 📝 Configuration

### Analytics Setup

Replace the placeholder IDs in each tool's HTML:

- **Google Analytics 4**: Replace `G-S9JM1LGH7L` with your Measurement ID
- **Google Search Console**: Replace `XXXXXXXXXXXXXXXX` with your verification code
- **Microsoft Clarity**: Replace `XXXXXXXXXX` with your Project ID

### Custom Domain (Optional)

1. Add a `CNAME` file with your domain name
2. Configure DNS records pointing to GitHub Pages
3. Enable HTTPS in repository settings
